Update the org chart data

Open the org chart

Guide (simple steps)

  1. Ask HR or IT for the latest org list as an Excel/CSV file. It must have these columns: id, name, title, parentId.
  2. Click Choose CSV below and pick that file.
  3. When the green/ready message appears, click Download data.js.
  4. Find the downloaded file (usually in your Downloads folder). Move it into the same folder as index.html, and replace the old data.js if asked.
  5. Open index.html (or refresh it) to see the updated chart.

You do not need Python, Node, internet, or special IT software for this page — only a normal web browser, with the packages folder next to this file. If anything fails, send this page and your CSV to IT.
