Update the org chart data

Open the org chart

Guide (simple steps)

  1. Ask IT for the latest org list as a CSV. Column titles can differ by market. IT keeps those names, and the location flags, in alias.json.
  2. This page loads alias.json from the same folder. If it cannot, click Mapping JSON and choose that file.
  3. Click Choose CSV and pick the org file. If a mapped column is missing, the message names it so IT can fix the file or the map. If some people rows are invalid, they are listed with a reason. You can skip those rows and still download data.js.
  4. When the ready message appears, click Download data.js.
  5. Find the downloaded file (usually in your Downloads folder). Move it into the same folder as index.html, and replace the old data.js if asked.
  6. Open index.html (or refresh it) to see the updated chart.

You do not need Python, Node, internet, or special IT software for this page — only a normal web browser, with the packages folder next to this file. If anything fails, send this page and your CSV to IT.
